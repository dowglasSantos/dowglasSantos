### 📂 Projetos em destaque

**🎵 YouTube Convert**
> API REST desenvolvida com Java e Spring Boot para download e conversão de vídeos em arquivos MP3.

- Integração com processos externos utilizando ProcessBuilder.
- Tratamento de exceções e respostas HTTP.
- Integração com yt-dlp e FFmpeg.
- Containerização com Docker.

**💬 ChatSphere**
> Projeto de backend para uma aplicação de comunicação entre usuários.

- Desenvolvimento de APIs REST com Spring Boot.
- Autenticação e autorização com Spring Security e JWT.
- Persistência de dados com PostgreSQL.
- Organização em camadas e tratamento de exceções.

**🌐 Memelândia**
> Projeto acadêmico desenvolvido com arquitetura baseada em microsserviços.

- Separação de responsabilidades entre serviços.
- Comunicação entre componentes da aplicação.
- Containerização utilizando Docker Compose.
- Integração de serviços utilizando Java e Spring Boot.
